# Time Series Forecasting using N-BEATS and LSTM

This project focuses on time series forecasting using deep learning models such as LSTM and N-BEATS. The objective is to predict future values from historical sequential data and compare the performance of both models.

The project includes data preprocessing, feature engineering, model training, evaluation, and visualization. Both univariate and multivariate forecasting approaches are implemented to analyze how multiple variables impact prediction accuracy.

The LSTM model captures long-term dependencies in sequential data, while N-BEATS provides highly accurate forecasting using a specialized neural architecture designed for time series analysis.

Technologies used in this project include Python, NumPy, Pandas, Matplotlib, Scikit-learn, and TensorFlow/Keras. Model performance is evaluated using metrics such as MAE, MSE, and RMSE.

This project demonstrates practical applications of deep learning in forecasting tasks like stock market prediction, sales forecasting, weather prediction, and business analytics.
